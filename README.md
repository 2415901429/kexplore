# AFTERGLOW – Event Management Website

AFTERGLOW is a modern, responsive event discovery and registration website designed to make finding and joining exciting events simple.

## Features

- Modern and responsive user interface
- Browse upcoming events
- Search events by name, category or venue
- Filter events by category
- View detailed event information
- Event registration form
- Form validation
- Registration confirmation message
- Dark and light mode
- Countdown timer
- Newsletter subscription
- Local Storage for saving registrations and preferences

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash Images
- Browser Local Storage

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.

## Deployment

The website can be deployed using GitHub Pages.

## Project Purpose

This project demonstrates front-end web development concepts, responsive design, JavaScript DOM manipulation, form validation and browser-based data storage.
